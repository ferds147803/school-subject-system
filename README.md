# 📚 School Subject Management System

A lightweight, command-line School & Subject Management System built with Python and SQLite.

## ✨ Features
- Add and manage academic subjects and assigned instructors.
- Register students with unique emails.
- Enroll students into subjects.
- Assign grades and calculate average GPAs/scores per student.
- Persistent local database using SQLite.
